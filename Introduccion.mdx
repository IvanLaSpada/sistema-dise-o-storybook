# Sistema de diseño SIAF

Un catálogo para diseñar y desarrollar interfaces consistentes. Reúne componentes funcionales, ejemplos interactivos y pautas de uso para UX y desarrollo.

## Cómo usar el catálogo

1. **Consultá Docs.** Encontrá el propósito, las reglas de uso, la anatomía, los estados y las consideraciones de accesibilidad del componente.
2. **Probá sus propiedades.** Cambiá los controles del ejemplo y comprobá cómo responde.
3. **Explorá las historias.** Revisá variantes concretas y galerías desde el menú lateral.
4. **Revisá el alcance.** Las pautas incluyen controles que aún requieren desarrollo. Cada página distingue lo documentado de lo disponible.

## Componentes documentados

- <a href="./?path=/docs/componentes-botones--docs" target="_top">Botones</a>: jerarquía, contenido, acciones destructivas y accesibilidad.
- <a href="./?path=/docs/componentes-input--docs" target="_top">Input</a>: etiquetas, ayuda, errores, contador y elección del campo según el dato.

## Diseño y documentación

Las pautas se sintetizan del documento **Pautas Diseño Aplicaciones SIAF**, aportado por UX el 28 de octubre de 2026. La apariencia actual de botones e input se desarrolló a partir de Figma. Cuando las especificaciones difieren, la página del componente identifica el punto que debe resolver UX.

Los ejemplos permiten evaluar el comportamiento de las piezas; su publicación no actualiza por sí sola las aplicaciones que las usan. La integración con un producto requiere adaptar el componente y comprobar su funcionamiento en ese contexto.
