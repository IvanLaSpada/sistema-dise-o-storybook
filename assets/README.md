- Roboto Medium 500: Google Fonts, servido localmente en `roboto-medium.ttf`, misma licencia SIL OFL. Usado en las etiquetas S.
- Icono `stars`: Google Material Icons, filled, Apache 2.0. Fuente: https://github.com/google/material-design-icons/blob/master/src/action/stars/materialicons/24px.svg
